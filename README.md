# HLCA — 365-Team Hoop Land Assets

Public image hosting for the fictional 365-team **HLCA college basketball league**.

## Completed asset sets
- `logos/` — **261** transparent PNG team logos, each **256×256 px**.
- `courts/` — **261** team-specific court overlays, each **1024×512 px**.
- `HLCA_261_COURTS_1024x512.zip` — downloadable collection containing all 261 courts and source credits.
- `court_teams.csv` — maps real NCAA school inspirations to fictional HLCA teams and colors.
- `court_sources.csv` — per-team provenance and image links.

## Community art credits
**119 courts** were adapted from public NCAA court images organized by [Hoop Land Designs](https://sites.google.com/view/hooplandcourts/ncaa), with original creator credits on each linked source page. For **142 other teams**, the package includes original fictional court designs. Community artwork was modified for the HLCA fictional team names and mascots, so the courts are **not exact unmodified NCAA court reproductions**.

## Game setup
The updated league TXT has direct URLs under each new team's `court.overlayURL` property. Public PNG URL example:

```
https://raw.githubusercontent.com/Treyhjhjh/HLCA-365-Logos/main/courts/Abilene%20Hurricane%20Hounds.png
```

Original 104 teams' art, all rosters, jerseys, team IDs, ratings and locations remain unchanged. To use these assets in Hoop Land, import the updated league TXT.
